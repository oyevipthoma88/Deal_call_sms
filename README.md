# 🔥 Bomber Bot - Telegram

SMS, WhatsApp aur Call bombing Telegram bot. Termux par chalta hai.

## Features
- 📱 SMS Bombing (multi-API)
- 💬 WhatsApp Bombing (pywhatkit)
- 📞 Call Bombing
- 🤖 Telegram Bot Interface
- ⚡ Async, fast

## Termux Setup
\`\`\`bash
pkg update && pkg upgrade
pkg install python git
pip install -r requirements.txt
\`\`\`

## Config
\`config.py\` mein apna BOT_TOKEN aur ALLOWED_USERS daal.

## Run
\`\`\`bash
python bot.py
\`\`\`
